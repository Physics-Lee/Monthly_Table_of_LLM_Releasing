# 国家及地区名单与人口

检索日期：2026-10-11。CSV使用UTF-8 BOM，便于Excel打开中文。

- `countries_195.csv`：联合国会员国193项，加圣座（梵蒂冈）及巴勒斯坦两个非会员观察员国。
- `countries_and_territories_249.csv`：ISO 3166-1的249个正式代码条目。
- `extra_54_population.csv`：249名单减去195名单所得54项，按可用人口从大到小排列，人口缺失项置后。

195名单定义依据：[联合国会员国](https://www.un.org/en/about-us/member-states)、[非会员观察员国](https://research.un.org/en/unmembers/observers)。代码和名称取自[公开country-codes数据集](https://github.com/datasets/country-codes/blob/master/data/country-codes.csv)，核对249个唯一ISO二位代码。ISO条目数量参见[英国政府代码规范](https://www.gov.uk/government/publications/open-standards-for-government/country-codes)及[ISO说明](https://www.iso.org/iso-3166-country-codes.html)。中文名为阅读名称，不替代ISO正式英文名称。

差集54项是名单口径差异，不表示54项具有相同政治或法律地位。库克群岛及纽埃是与新西兰自由联系的自治实体，也不在本次195口径内。科索沃没有正式ISO 3166-1代码，不在本次249名单中。

人口主数据为[联合国WPP 2024版经OWID整理的数据](https://ourworldindata.org/grapher/population-unwpp)，取2023年7月1日人口估计。这是该历史估计序列的最新年份，不是2026年实时人口。奥兰、斯瓦尔巴使用2023年当地官方数据；圣诞岛、科科斯群岛、诺福克岛和皮特凯恩采用2021年官方资料。每行标注人口年份、定义、补充说明及来源URL。

差集中41项采用UN 2023年估计，合计39,520,475人；另6项官方补充数据合计38,148人。共47项可用数据小计39,558,623人，约3956万人。由于补充数据年份和时点不同，这个小计是近似量级，不能解读为严格统一时点的总人口。

剩余7项是南极洲、布维岛、南乔治亚和南桑德韦奇群岛、赫德岛和麦克唐纳群岛、英属印度洋领土、法属南方领地、美国本土外小岛屿。未取得可比常住人口，人口栏留空；留空不等于0，也不把驻军、科研或季节性工作人员当作可比常住人口填入。

斯瓦尔巴和扬马延的补充数字3094仅为斯瓦尔巴2023年7月1日定居点人口，不含扬马延轮换驻站人员。地区人口可能已经包含在其所属国家人口中，例如奥兰之于芬兰；不能直接把本差集人口加到195项国家人口之和。

核验：195和54名单不重叠，二者并集恰为249名单；各文件代码唯一；CSV重新读入后记录数、人口小计及缺失项均一致。
