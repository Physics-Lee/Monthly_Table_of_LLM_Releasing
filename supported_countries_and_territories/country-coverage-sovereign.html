主权国家覆盖（官方清单折算，降序）

三家均有官方逐项清单，可精确折算；虚线框为满分线 195（193 会员国 + 梵蒂冈、巴勒斯坦 2 观察员国）。Gemini 行采用 Gemini API / AI Studio 官方地区清单折算（见口径说明），非消费版应用的官方数字。

折算明细

本页采用“联合国会员国 + 观察员国（圣座／梵蒂冈、巴勒斯坦）”作为国家统计集合；其他条目不计入。折算为编者完成，基于各家官方清单原文；不将所有未计入条目统称为属地。

无法折算的服务

这些服务只公布"国家与地区"混合总数、或干脆没有清单，无法拆出主权国家数——混合口径的对比见含地区版页面。

事项说明
国家统计口径联合国会员国 193 个 + 观察员国 2 个（圣座／梵蒂冈、巴勒斯坦）= 195 个，作为本页统计集合。科索沃、中国台湾、西撒哈拉、库克群岛、纽埃等均不在此集合内，故不计入；该分类仅用于本页统计。
各家清单的折算OpenAI API：208 项 = 185 会员国 + 2 观察员国 + 21 个其他条目（中国台湾及 20 个属地；2026-10-22 复核）；Gemini API：230 项 = 184 会员国 + 2 观察员国 + 44 个其他条目；Anthropic：185 项 = 182 会员国 + 2 观察员国 + 1 其他条目（中国台湾）。Gemini API 的其他条目包含属地、南极洲及科索沃等，不宜统一称为属地。Anthropic 还支持已列国家的属地，185 不是完整覆盖地区数，但不影响本页国家数折算。
Gemini 的产品范围本页图表采用Gemini API / AI Studio 清单（230 项）折算为 186 个国家。Gemini 网页版帮助页也有逐项清单，本次清点为 242 项；排除仅限 Workspace 的中国大陆条目后，为 185 会员国 + 2 观察员国 + 54 个其他条目，共覆盖 187 个本页口径的国家。网页版与 API 版支持地区不同。
跨页面比较含地区版同时列出清单计数、下限与历史公告数字，不能用于严格排名；其中 Gemini 网页版与本页 API 版的范围也不同。不能据此宣称“只剔除属地后，OpenAI 反超 Gemini”。
多覆盖了哪些国家相较 Gemini API，OpenAI API 多支持阿富汗、缅甸；Gemini API 多支持委内瑞拉。Anthropic 比 OpenAI API 另缺阿富汗、缅甸、也门。图表中的三项服务覆盖数为 184～187，不能据此推导用户数量或市场份额。
